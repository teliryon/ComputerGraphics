# Лабораторная работа №1: OpenTK (Графические примитивы)

Этот проект демонстрирует работу с графикой на C# с использованием библиотеки **OpenTK**. Программа открывает графическое окно и рисует различные примитивы (линии, треугольники, квадраты, шестиугольники), а также позволяет менять их размер в реальном времени.

---

## Шаг 1: Что нужно установить (делается 1 раз)

Чтобы программа заработала, на компьютере должен быть установлен **.NET SDK**.
1. Перейди по ссылке: [https://dotnet.microsoft.com/download](https://dotnet.microsoft.com/download)
2. Скачай и установи **.NET 8.0 SDK** (или любую более новую версию, например, .NET 10).
3. После установки **перезагрузи компьютер** (или хотя бы перезапусти терминал/VS Code), чтобы система увидела новую программу.

---

## Шаг 2: Как получить проект

1. Нажми зеленую кнопку **<> Code** сверху на странице GitHub.
2. Выбери **Download ZIP**.
3. Распакуй скачанный архив в любую удобную папку на компьютере.

---

## Шаг 3: Как запустить (2 простые команды)

Есть два способа запустить проект. Выбери тот, который тебе удобнее:

### Способ А: Через Visual Studio Code (Рекомендуется)
1. Открой **Visual Studio Code**.
2. Нажми `Файл` -> `Открыть папку...` и выбери распакованную папку с проектом (`OpenTK_Lab1`).
3. В верхнем меню выбери `Терминал` -> `Создать терминал` (или нажми `` Ctrl + ` ``).
4. Введи по очереди эти две команды (нажимая Enter после каждой):
   ```bash
   dotnet restore
   dotnet run
